# Français VN — application iPhone

## Mettre l'application en ligne (une seule fois, gratuit, depuis un ordinateur)
1. Créez un compte sur https://github.com (gratuit).
2. Bouton « + » en haut à droite → **New repository**. Nom : `francais-vn`. Cochez **Public**. → **Create repository**.
3. Cliquez sur **uploading an existing file**. Glissez **tout le contenu** de ce dossier (index.html, sw.js, manifest.webmanifest et les dossiers css, data, icons, js, snd) → **Commit changes**.
4. **Settings** → **Pages** → Source : **Deploy from a branch** → Branch : **main**, dossier **/ (root)** → **Save**.
5. Après 1 à 2 minutes, l'adresse s'affiche : `https://VOTRE-NOM.github.io/francais-vn/`

## Installer sur l'iPhone
1. Ouvrez cette adresse dans **Safari** (pas Chrome), avec Internet.
2. Bouton **Partager** (carré avec une flèche ↑) → **Sur l'écran d'accueil** → **Ajouter**.
3. Ouvrez l'application depuis son icône : elle s'ouvre en plein écran, sans Safari. Attendez quelques secondes au premier lancement (téléchargement de 3 Mo) : ensuite elle fonctionne **sans Internet**.

## Bon à savoir
- Il faut iOS 16.4 ou plus récent (iPhone 8 et suivants).
- La progression est enregistrée sur le téléphone. Sauvegardez-la de temps en temps : Réglages → « Sauvegarder ce profil » (fichier `.efv` dans l'app Fichiers).
- Exercices oraux : ils utilisent la reconnaissance vocale de l'iPhone, qui peut demander Internet. Autorisez le micro quand l'iPhone le demande.
- Voix française : Réglages iPhone → Accessibilité → Contenu énoncé → Voix → Français (pour une voix de meilleure qualité).
- Vraies photos : elles sont téléchargées depuis Wikipédia la première fois (Réglages → Télécharger les photos), puis restent sur le téléphone.
- Mise à jour : remplacez les fichiers sur GitHub ; l'iPhone prend la nouvelle version au lancement suivant.

# Français VN — ứng dụng iPhone

## Đưa ứng dụng lên mạng (chỉ một lần, miễn phí, trên máy tính)
1. Tạo tài khoản tại https://github.com (miễn phí).
2. Nút « + » góc trên phải → **New repository**. Tên: `francais-vn`. Chọn **Public** → **Create repository**.
3. Bấm **uploading an existing file**. Kéo **toàn bộ nội dung** thư mục này vào → **Commit changes**.
4. **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: **main**, thư mục **/ (root)** → **Save**.
5. Sau 1–2 phút sẽ có địa chỉ: `https://TEN-CUA-BAN.github.io/francais-vn/`

## Cài trên iPhone
1. Mở địa chỉ đó bằng **Safari** (khi có Internet).
2. Nút **Chia sẻ** (hình vuông có mũi tên ↑) → **Thêm vào MH chính** → **Thêm**.
3. Mở ứng dụng từ biểu tượng: ứng dụng mở toàn màn hình. Lần đầu chờ vài giây (tải 3 MB); sau đó dùng được **không cần Internet**.
